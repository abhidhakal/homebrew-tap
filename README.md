# Homebrew Tap for AuthG

This is the official Homebrew tap for [AuthG](https://authg.abhinavdhakal.com), the open-source, privacy-first desktop 2FA authenticator.

## Installation

To install AuthG via Homebrew:

```bash
brew install --cask abhidhakal/tap/authg
```

Or tap this repository first:

```bash
brew tap abhidhakal/tap
brew install --cask authg
```

## Updates

To update AuthG to the latest release:

```bash
brew upgrade --cask authg
```

## Uninstall

```bash
brew uninstall --cask authg
```

To also remove application support and configuration caches:

```bash
brew zap authg
```
